# SessionChat

**Лёгкий чат-оверлей, который подключается к твоей игровой сессии Roblox.**

[English](README.md) · [Русский](README.ru.md) · [Сайт проекта](https://h1nchek.github.io/session-chat/) · [Скачать для Windows](https://github.com/h1nchek/session-chat/releases/latest)

## Что такое SessionChat?

SessionChat — open-source чат для совместной игры в Roblox в реальном времени. Оверлей для Windows определяет активный игровой сервер по локальному логу Roblox и подключается к соответствующей комнате.

> **Статус проекта:** ранняя версия community-проекта. Клиент-оверлей работает только на Windows. Перед запуском собственного сервера обязательно прочитай раздел о безопасности.

## Возможности

- **Автоопределение сессии** — подключение по текущим `PlaceId` и `JobId`.
- **Игровой оверлей** — режим сквозных кликов, настройка прозрачности, перемещение окна и горячая клавиша **T**.
- **Чат сервера и игры** — общение на одном сервере или команда `/global` для чата всего режима.
- **Приватные комнаты** — создание временной комнаты и приглашение друзей по 4-значному коду.
- **Упоминания и уведомления** — подсветка `@твоё_имя` и необязательный тихий звук уведомления.
- **Управление чатом** — локальная команда `/mute Nick`, настройка ника и базовая серверная фильтрация спама и мошеннических сообщений.
- **Android-приложение-компаньон** — подключение к сессии ПК по коду или поиск игры по названию / PlaceId.

## Начало работы

### Приложение для Windows

1. Открой страницу [GitHub Releases](https://github.com/h1nchek/session-chat/releases).
2. Скачай `SessionChat.exe` из последнего релиза.
3. Запусти приложение и выбери ник.

Для готового EXE устанавливать Python не требуется.

### Запуск из исходного кода

Требования: Windows, Python 3.10+ и пакеты из `requirements.txt`.

```bash
python -m pip install -r requirements.txt
python client.py
```

По умолчанию клиент подключается к `ws://127.0.0.1:8765`. Чтобы использовать другой сервер, измени `SERVER_URL` в начале файла `client.py`. Если логи Roblox находятся в нестандартной папке, задай переменную окружения `ROBLOX_LOG_DIR`.

### Запуск сервера

```bash
python -m pip install -r requirements.txt
python server.py
```

По умолчанию сервер слушает `0.0.0.0:8765`. Настрой клиент на адрес, доступный с твоего устройства.

**Не открывай текущий сервер напрямую в публичный интернет.** Подробности — в разделе [Безопасность и конфиденциальность](#безопасность-и-конфиденциальность).

## Управление оверлеем

| Клавиша / элемент | Действие |
| --- | --- |
| `T` | Открыть поле ввода |
| `Enter` | Отправить сообщение |
| `Escape` | Закрыть ввод и вернуть режим сквозных кликов |
| Значок шестерёнки | Открыть настройки ника, прозрачности и комнат |
| `×` в заголовке / `Exit SessionChat` в настройках | Полностью закрыть приложение |
| Перетаскивание заголовка | Переместить оверлей в интерактивном режиме |
| `/mute Nick` | Локально скрыть сообщения пользователя |
| `/global` или `/global on` | Перейти в общий чат всей игры |
| `/global off` | Вернуться в чат текущего сервера |
| `@ТвойНик` | Упомянуть игрока |

Чтобы подключиться к комнате друга, открой **Settings → Join by code** и введи 4-значный код. Кнопка **Create private** создаёт временную приватную комнату.

## Android-приложение

Проект Android находится в папке `android/`. Открой её в Android Studio и дождись синхронизации Gradle.

Возможности:
- Подключение к точной сессии игрока на ПК по 4-значному коду.
- Поиск игр Roblox по названию.
- Прямой ввод числового `PlaceId`.
- Чтение и отправка сообщений.

Для локального сервера укажи WebSocket URL. Адрес `ws://10.0.2.2:8765` по умолчанию предназначен для Android Emulator, когда сервер запущен на компьютере.

## Безопасность и конфиденциальность

SessionChat — ранний проект, а не защищённый публичный чат-сервис.

- В текущей версии сервера **нет** авторизации аккаунтов, шифрования соединения и постоянной истории сообщений.
- Ограничение частоты сообщений и базовая фильтрация спама/мошеннических фраз не заменяют авторизацию и модерацию.
- Идентификаторы комнат берутся из локальных логов Roblox и не проверяются самой платформой Roblox.
- Не запускай недоверенный публичный сервер и не выставляй порт `8765` напрямую в интернет. Для интернет-развёртывания нужны защищённый адрес `wss://`, авторизация, сетевые меры защиты и модерация.
- Для определения текущей игровой сессии оверлей читает локальные файлы логов Roblox.

### Прозрачность сборки Windows

Релизы с тегами собираются через GitHub Actions. В релизе предполагаются следующие файлы:
- `SessionChat.exe` — приложение для Windows.
- `SHA256SUMS.txt` — контрольная сумма для проверки целостности файла.
- GitHub build-provenance attestation — сведения об исходной ревизии и процессе сборки.

Контрольная сумма помогает обнаружить изменённый файл, но **не доказывает отсутствие вредоносного кода**. Зависимости и среда сборки также влияют на безопасность.
