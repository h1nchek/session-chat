Built for playing together

SessionChat detects the active Roblox game session on Windows and opens the matching chat room automatically.

Session-aware overlay

Automatic PlaceId + JobId room detection, click-through overlay, nickname and opacity settings.

Find your people

Private rooms with temporary invite codes, cross-server global chat, mentions and soft notifications.

Android companion

Join a PC session with an invite code or discover an experience by name or PlaceId.

Open source. Transparent by design.

The source is public so users can inspect how the client and server work, build it themselves, and review changes.

Build transparency

Tagged releases are built by GitHub Actions. Release assets include a SHA-256 checksum and build-provenance attestation.

Honest security status

The current server is an early prototype: it has no account authentication or transport encryption by itself. Do not expose it directly to the public internet. Use a secured WSS deployment with authentication and moderation before public use.
