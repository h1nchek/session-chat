WHY SESSIONCHAT

Made to stay in the game.

Useful chat tools, without pulling you away from the experience.

ВОЗМОЖНОСТИ

Общение прямо во время игры.

Нужные инструменты чата, не отвлекающие от игрового процесса.

⌖

Session-aware overlay

Automatically detects your Roblox PlaceId and JobId and opens the matching chat room.

◎

Private rooms

Create temporary invite rooms and bring friends in with a simple 4-digit code.

⇄

Cross-server chat

Use the global room to talk with players across servers in the same experience.

@

Mentions

Get highlighted when someone mentions your nickname in chat.

♫

Soft notifications

Optional incoming-message tone with a quick on/off switch.

▣

Android companion

Join a PC session by code or find an experience by name or PlaceId.

⌖

Оверлей игровой сессии

Автоматически определяет PlaceId и JobId Roblox и открывает нужную комнату.

◎

Приватные комнаты

Создавайте временные комнаты и приглашайте друзей по короткому 4-значному коду.

⇄

Общий чат игры

Общайтесь с игроками из разных серверов одного игрового режима.

@

Упоминания

Сообщения с вашим ником автоматически подсвечиваются.

♫

Тихие уведомления

Необязательный звук новых сообщений с быстрым переключателем.

▣

Android-компаньон

Подключайтесь к сессии ПК по коду или находите игру по названию и PlaceId.

GET STARTED

Up and running in minutes.

Download the Windows build or explore the source and build it yourself.

НАЧАЛО РАБОТЫ

Начните за пару минут.

Скачайте сборку для Windows или изучите исходный код и соберите приложение самостоятельно.

01 / DOWNLOAD

Get the app

Open GitHub Releases and download the Windows executable when a release is available.

02 / LAUNCH

Choose a nickname

Run SessionChat and enter the nickname you want to use in chat.

03 / PLAY

Join your session

Start Roblox. SessionChat watches the local game log and joins the matching room.

01 / СКАЧАТЬ

Получите приложение

Откройте GitHub Releases и скачайте EXE для Windows, когда будет опубликован релиз.

02 / ЗАПУСТИТЬ

Выберите ник

Запустите SessionChat и укажите имя, которое будет отображаться в чате.

03 / ИГРАТЬ

Подключитесь к сессии

Запустите Roblox. SessionChat отслеживает локальный лог игры и подключает нужную комнату.

Current security status

Текущее состояние безопасности

This is an early prototype. The server currently has no account authentication, transport encryption or persistent history. Basic rate limits and scam filtering are not a substitute for proper security and moderation. Do not expose the server directly to the public internet.

Это ранний прототип. Сейчас на сервере нет авторизации аккаунтов, шифрования соединения и постоянной истории. Базовые лимиты и фильтрация мошеннических сообщений не заменяют полноценную защиту и модерацию. Не открывайте сервер напрямую в публичный интернет.
